# Hugging Face README YAML Examples

Hugging Face displays custom licenses through README card metadata. For DDL,
use `license: other`, set `license_name` to the DDL identifier, and set
`license_link` to the canonical DDL text or registry entry.

## Operative Licenses

```yaml
---
license: other
license_name: DDL-D-1.2
license_link: https://raw.githubusercontent.com/scarletdeathx/DDL/main/licenses/DDL-D-1.2.md
---
```

```yaml
---
license: other
license_name: DDL-V-1.2
license_link: https://raw.githubusercontent.com/scarletdeathx/DDL/main/licenses/DDL-V-1.2.md

```

## Profiles

For profiles, link to the registry because the profile expands to an operative
license plus release-posture rules.

---
license: other
license_name: DDL-VX-1.2
license_link: https://raw.githubusercontent.com/scarletdeathx/DDL/main/identifiers.md
---
